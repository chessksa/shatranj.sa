# تصميم تنقل أقسام لوحة العضو بالأيقونات

## الهدف
تحويل أقسام الأصدقاء والطلبات والتحديات في `profile.html` من صفوف قابلة للفتح داخل الصفحة إلى شريط أيقونات متناسق ومختصر، مع فتح التفاصيل في صفحة مستقلة موحدة.

## صفحة العضو
- الإبقاء على بطاقة اللاعب والإحصاءات أعلى الصفحة.
- الإبقاء على **آخر المباريات** و**الإنجازات** ظاهرة داخل صفحة العضو كما هي.
- استبدال الأقسام الخمسة الحالية بشريط واحد من خمس أيقونات متجاورة ومتساوية الحجم:
  1. الأصدقاء
  2. طلبات الصداقة
  3. الطلبات المرسلة
  4. التحديات
  5. التحديات المرسلة
- يظهر العدد بجانب الأيقونة في نفس العنصر، وليس كسطر مستقل.
- جميع العناصر متساوية في الارتفاع والعرض البصري، مع تنسيق متجاوب للجوال.
- الضغط على أي عنصر ينتقل إلى صفحة التفاصيل الموحدة بدل فتح المحتوى داخل `profile.html`.

## صفحة التفاصيل الموحدة
إنشاء صفحة واحدة مثل `profile-section.html`، وتستقبل نوع القسم عبر query parameter مثل:
- `?section=friends`
- `?section=friend-requests`
- `?section=sent-requests`
- `?section=challenges`
- `?section=sent-challenges`

الصفحة تعرض:
- عنوان القسم المناسب.
- زر رجوع إلى لوحة العضو.
- نفس بيانات وأزرار الإجراءات الموجودة حاليًا لكل قسم، دون تغيير وظائفها.
- نفس ألوان الواجهة الرئيسية ونفس أسلوب البطاقات والمسافات المضغوطة.

## البيانات والسلوك
- إعادة استخدام RPCs الحالية وعدم تغيير قاعدة البيانات.
- الأصدقاء: `get_my_friends`.
- طلبات الصداقة الواردة والمرسلة: `get_my_friend_requests` مع تصفية الاتجاه.
- التحديات الواردة والمرسلة: `get_my_friend_challenges` مع تصفية الاتجاه والحالة.
- الإبقاء على قبول/رفض/إلغاء الطلبات والتحديات وفتح الملفات العامة وتحدي الصديق كما تعمل حاليًا.
- الإبقاء على آلية فتح المباراة المقبولة من التحديات كما هي.

## الملفات المتوقعة
- تعديل `profile.html` لإضافة شريط الأيقونات وإزالة المحتوى القابل للطي.
- تعديل `profile.js` ليحمّل الأعداد فقط لهذه الأقسام في لوحة العضو.
- إضافة `profile-section.html`.
- إضافة `profile-section.js` لإدارة تحميل القسم المحدد وإجراءاته.
- اختبارات جديدة للتحقق من التنقل، تساوي الأيقونات، ظهور الأعداد، وعدم كسر آخر المباريات والإنجازات.

## معايير القبول
- لا توجد قوائم أصدقاء/طلبات/تحديات قابلة للفتح داخل `profile.html`.
- توجد خمس أيقونات متجاورة ومتناسقة بالحجم.
- يظهر العدد بجانب كل أيقونة.
- كل أيقونة تفتح صفحة التفاصيل الصحيحة.
- صفحة التفاصيل الواحدة تعرض البيانات الصحيحة حسب `section`.
- آخر المباريات والإنجازات تبقيان ظاهرتين في لوحة العضو.
- لا تغيير على قاعدة البيانات أو منطق اللعب.
