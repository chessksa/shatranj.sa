# شطرنج العرب

الموقع يعمل بوصفه تطبيق ويب ثابتًا مستضافًا على GitHub Pages مع Supabase للمصادقة والبيانات والخدمات الخلفية.

## الملفات المعتمدة
- `index.html`: الواجهة الرئيسية المعتمدة (كمبيوتر وجوال).
- `v2/home/` و`v2/site/`: وظائف وتنسيقات الواجهة الحديثة؛ لا تُحذف بوصفها إصدارات قديمة لمجرد وجود v2 في الاسم.
- `play-entry-v16.html`: مدخل اللعب من الواجهة.
- `play-v10.html` و`play.html`: مسارات لعب ما زالت موجودة ويجب فحص الروابط قبل تغييرها.
- `tournaments.html` و`tournaments-app.html`: واجهة البطولات.
- `admin.html`: لوحة الإدارة.
- `supabase/`: الترحيلات والدوال الخلفية؛ لا تُحذف الترحيلات التاريخية.
- `CNAME`: ربط النطاق `arabchees.com`.

## التوافق مع الروابط القديمة
تُترك صفحات التحويل مثل `index-app.html` و`play-v8.html` لتوجيه الروابط السابقة، ولا تُحذف دون فحص استخدامها.

## طريقة التطوير
تُعدّل الملفات المصدرية النهائية مباشرة، لا بإضافة إجراءات GitHub Actions مؤقتة تعيد كتابة صفحات الموقع. حُذفت إجراءات التعديل القديمة المعطلة وملفات التصحيحات التي لا تدخل في تشغيل النسخة الحالية، مع الاحتفاظ بسجل Git لاسترجاعها عند الحاجة.

## التحقق
توجد اختبارات في `tests/` وسير عمل تحقق في `.github/workflows/`. تُراجع الاختبارات وتوافق الكمبيوتر والجوال قبل أي تغيير في تصميم الإنتاج، مع المحافظة على ترتيب تحميل CSS وJS عند توحيدها.
