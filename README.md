# شطرنج العرب — النسخة الثانية

## تعمل الآن بدون أي حساب خارجي
افتح `index.html` في متصفح حديث. التسجيل والتصنيف سيعملان محليًا باستخدام LocalStorage.

## عند ربط Supabase
1. أنشئ مشروعًا مجانيًا.
2. شغّل `schema.sql` في SQL Editor.
3. من Project Settings > API انسخ Project URL و anon public key.
4. افتح `config.js`:
   - enabled: true
   - ضع url
   - ضع anonKey
5. ارفع الملفات إلى GitHub Pages أو Cloudflare Pages.
